# TODO

依存ライブラリなしで動くシンプルな TODO アプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 機能

- タスクの追加（Enter または「追加」ボタン）
- 完了 / 未完了の切り替え、すべて完了にする
- 編集（テキストをダブルクリック、または ✎ ボタン。Enter で確定、Esc で取り消し、空にすると削除）
- 削除、完了済みの一括削除
- 「すべて / 未完了 / 完了済み」での絞り込み（URL の `#/active` などで保持）
- `localStorage` への自動保存（別タブでの変更も反映）
- ダークモード、スマートフォン表示に対応

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | スタイル |
| `app.js` | 状態管理・描画・イベント処理 |
